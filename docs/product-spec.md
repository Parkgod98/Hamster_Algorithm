# Product Spec

## 문제
현재 스터디원은 BaekjoonHub가 GitHub에 자동 커밋한 결과를 다시 캡처하고 Notion에 올려 인증합니다. 실제 풀이 기록은 이미 GitHub에 있는데 사람이 같은 사실을 다시 옮기고 있습니다.

Hamster Algorithm은 각자의 Repository에서 발생한 풀이 이벤트를 자동 수집해 스터디 규칙으로 판정하고, 인증/미루기/미리 풀기/벌금/통계를 한 화면에서 관리하는 PWA를 목표로 합니다.

## 사용자 흐름
1. GitHub OAuth로 최초 로그인합니다. 이후 직접 로그아웃하기 전까지 저장된 Supabase session을 복원해 바로 Dashboard로 진입합니다.
2. 햄쮸터 Study를 만들거나 초대 코드/링크로 참여합니다.
3. GitHub App을 설치하고 자신의 알고리즘 Repository만 선택합니다.
4. 이후 문제를 평소처럼 풀고 BaekjoonHub가 push하면 자동 인증됩니다.
5. BaekjoonHub에 올라오지 않은 풀이는 날짜 상세에서 플랫폼/난이도/문제 수만 골라 수동 인증합니다.
6. Dashboard의 월간 캘린더에서 같은 Study 멤버의 인증 상태와 풀이 내역을 확인합니다.
7. 모바일에서는 월간/주간 보기를 전환할 수 있습니다.
8. 통계 탭에서 멤버별 월간 인증률, 완료/미제출/미루기, 연속 인증, 누적 벌금을 확인합니다.
9. 같은 통계 탭에서 본인 또는 같은 Study 멤버를 선택해 이번 달 풀이량, 플랫폼별 난이도 분포, 주간 난이도 추세와 최근 3개월 도전 수준을 확인합니다.
10. 못 푸는 날은 설정된 미루기 마감 전 미루기를 신청합니다.
11. Study 참여원 누구나 설정에서 문제 수, 미루기/선풀이 한도, 벌금 규칙을 조정할 수 있습니다.
12. 사용자는 PWA에서 Push 알림을 켜 인증 완료와 미인증 reminder를 받을 수 있습니다.

## 기본 햄쮸터 규칙
- BOJ Bronze 2~1: 3문제
- BOJ Silver 5~1: 2문제
- BOJ Gold 5 이상: 1문제
- SWEA D2~D3: 2문제
- SWEA D4 이상: 1문제
- Programmers Lv.0~1: 3문제
- Programmers Lv.2 이상: 1문제
- CodeTree 삼성 기출: 1문제
- 제출 마감: 오전 4시
- 미루기 신청 마감: 당일 23:59
- 미루기: 미해결 의무 최대 2일치까지 유지 가능
- 미리 풀기: 최대 2일
- 미제출 벌금: 1일 10,000원 / 2일 연속 25,000원 / 3일 이상 50,000원

## 미루기 / backlog / 선풀이
미루기는 해당 날짜의 인증 의무를 없애는 기능이 아니라 다음 날로 이월하는 기능입니다.

- 매 Study Day마다 1일치 인증 의무가 생깁니다.
- 풀이는 가장 오래된 미해결 의무부터 FIFO로 상환합니다.
- 9/15를 미루고 9/16도 미뤘다면 9/17에는 9/15, 9/16, 9/17 총 3일치를 해결해야 오늘까지 완료입니다.
- 위 상태에서 9/17에 1일치를 풀면 9/15가 완료되고 9/16·9/17 두 의무가 남습니다.
- 2일치를 풀면 9/15·9/16이 완료되고 9/17 한 의무가 남습니다.
- 3일치를 풀면 세 날짜가 모두 완료됩니다.
- 부분 credit은 가장 오래된 의무에 쌓이지만 1.0을 채워 하루를 통째로 해결하기 전에는 `하루 상환`으로 세지 않습니다. 예를 들어 3일치가 밀린 상태에서 0.5일치만 풀면 여전히 3일치가 미해결입니다.
- 기본 `maxConsecutivePostpone=2`에서는 현재 미해결 의무가 2일치 이하일 때만 오늘 미루기를 신청할 수 있습니다. 3일치가 밀렸다면 최소 1일치를 완전히 해결해야 다시 미룰 수 있습니다.
- 미루기를 신청한 오늘은 신규 벌금을 부과하지 않고 오늘 의무를 backlog로 남깁니다.
- backlog를 전부 갚은 뒤 남는 초과 credit만 `maxPresolveDays` 범위에서 미래 선풀이로 사용합니다.
- 과거 미루기 날짜를 나중에 상환하면 해당 날짜의 현재 상태는 `완료`로 재계산하지만 미루기 신청 이력은 유지합니다.

## 벌금
- 미루기를 사용하지 않은 Study Day가 04:00에 마감되고 미해결 의무가 남으면 벌금 대상입니다.
- 마감 시 남은 미해결 의무가 1일치면 1회 벌금, 2일치면 2회 벌금, 3일치 이상이면 3회 최고 벌금입니다.
- 3일치를 초과해 밀려도 금액 단계는 3회 최고 벌금으로 cap합니다.
- 한번 `hamster_penalties`에 확정된 벌금은 이후 그 과거 의무를 상환해 완료로 바뀌어도 취소하거나 소급 수정하지 않습니다.

## 간편 수동 인증
자동 수집이 불가능한 풀이를 위해 사진 업로드 없이 최소 입력만 받습니다.

- 입력: 플랫폼 / 난이도 구간 / 문제 수
- 지원 플랫폼: BOJ / Programmers / SWEA / CodeTree
- 문제 번호, 문제명, 이미지, 메모는 저장하지 않습니다.
- 로그인한 사용자는 본인 풀이만 등록할 수 있습니다.
- 미래 날짜와 Study 참여 전 날짜에는 등록할 수 없습니다.
- 수동 풀이도 자동 풀이와 동일한 Rule Engine의 credit으로 계산하고 같은 날 자동/수동 풀이를 합산합니다.
- DB에는 기존 `hamster_problems`, `hamster_submissions`를 재사용하며 `source=manual`로 구분합니다.
- 날짜 상세에서는 `수동` 배지를 표시합니다.

## Study별 규칙 설정
기본값은 위 원문 규칙을 그대로 사용하되 해당 Study 참여원이라면 누구나 다음 값을 변경할 수 있습니다.

- 플랫폼/난이도 구간별 하루 필요 문제 수
- 미루기 신청 마감 시각
- 미해결 의무를 유지하며 미룰 수 있는 최대 일수
- 미리 풀기 최대 일수
- 미제출 1/2/3일 벌금

Study Day 경계인 04:00은 현재 운영 cron의 04:05 확정 시점과 결합되어 있으므로 임의 변경을 허용하지 않습니다. cutoff를 바꾸려면 cron 스케줄까지 함께 설계·변경해야 합니다.

규칙은 `hamster_study_rule_versions`에 Study Day 단위로 버전이 기록됩니다. 변경일 이전 날짜는 이전 규칙, 변경일 이후 날짜는 새 규칙으로 계산합니다. 같은 Study Day에 여러 번 저장하면 해당 날짜의 최신 설정으로 갱신합니다. 이미 `hamster_penalties`에 확정된 과거 벌금 row는 자동 소급 수정하지 않습니다.

## 풀이 성장 통계
풀이 성장 통계는 인증 여부와 별개로 `hamster_submissions`의 실제 풀이 기록을 집계합니다. 같은 Study 멤버끼리는 서로의 성장 통계를 조회할 수 있습니다.

- 기본 선택은 로그인한 본인입니다.
- 통계 탭의 멤버 선택 또는 월간 통계 카드를 통해 같은 Study 멤버의 성장 통계로 전환할 수 있습니다.
- 서버는 요청자의 Study membership을 기준으로 대상 사용자가 같은 Study 멤버인지 검증하며, 다른 Study 사용자의 통계 조회는 허용하지 않습니다.

- 자동/수동 풀이를 모두 submission 1건 = 풀이 1문제로 집계합니다.
- 수동 인증은 문제 번호를 저장하지 않으므로 `고유 문제 수`가 아니라 `풀이 수`를 기본 지표로 사용합니다.
- 월/주 집계 날짜는 Study Day(Asia/Seoul 04:00) 기준입니다.
- 선택한 달의 총 풀이 수, 전월 대비 증감, 활동일, 활동일 기준 평균 풀이 수를 보여줍니다.
- 플랫폼별 풀이 수와 난이도 분포를 보여줍니다.
- BOJ는 Bronze V부터 Ruby I까지, Programmers는 Level, SWEA는 D 레벨 순서를 각 플랫폼 내부에서만 비교합니다.
- CodeTree 삼성 기출은 난이도 서열 점수로 환산하지 않고 풀이 수만 집계합니다.
- 상위 난이도 비중은 BOJ Gold 이상, Programmers Lv.2 이상, SWEA D4 이상을 기준으로 계산합니다.
- 주별 평균 난이도와 최근 3개월 평균 난이도/상위 난이도 비중을 보여줍니다.
- 서로 다른 플랫폼의 난이도 점수를 합산해 하나의 `실력 점수`로 만들지 않습니다.
- 난이도 상승은 곧바로 실력 향상으로 단정하지 않고 `난이도 추세`, `도전 수준`, `상위 난이도 비중`으로 표현합니다.

## Push 알림
알림은 사용자가 직접 켠 기기에서만 발송합니다.

- 인증 완료: 자동 또는 수동 풀이가 반영된 뒤 현재 Study Day까지의 backlog와 오늘 의무가 모두 해결되어 `미완료 → 완료`로 처음 전환되는 순간 `🐹 오늘 인증 완료! 수고했다 쮸!`를 전송합니다.
- 과거 backlog만 일부 상환하고 오늘 의무가 남아 있으면 완료 Push를 보내지 않습니다.
- 미인증 reminder: 23:30 KST 이후 현재 Study Day까지 미해결 의무가 남아 있고 오늘 미루기도 신청하지 않은 사용자에게 `🐹 아직 오늘 인증이 안 됐어. 04:00 전까지 풀거나 미루기 신청해줘! 쮸!`를 전송합니다.
- 같은 Study Day/사용자/알림 종류/기기 subscription은 성공 후 한 번만 발송합니다.
- Push 실패는 인증 저장 성공 여부에 영향을 주지 않습니다.
- 일시적 Push 실패는 같은 요청에서 한 번 재시도하고, 실패 상태는 이후 reminder 실행에서 다시 시도할 수 있습니다.
- 완료 또는 오늘 미루기 상태에는 reminder를 보내지 않습니다.
- Push endpoint가 404/410으로 만료되면 구독 정보를 제거합니다.
- 사용자는 완료 알림과 reminder를 각각 켜거나 끌 수 있습니다.
- 알림 설정 UI는 계정 전체가 아니라 현재 기기의 Push subscription을 기준으로 표시합니다.
- 사용자는 `테스트 알림 보내기`로 현재 기기의 실제 Push 수신 여부를 즉시 확인할 수 있습니다.
- Android는 지원 브라우저/PWA에서 사용하며 iPhone은 홈 화면에 추가한 PWA에서 알림 권한을 허용해야 합니다.
- Vercel Hobby Cron은 분 단위 정각 실행을 보장하지 않으므로 23:30 스케줄과 자정 backup 스케줄을 함께 두고, 서버에서 23:30 이전 실행은 차단합니다.

## 제품 해석이 필요한 부분
원문에는 서로 다른 난이도/플랫폼 문제를 같은 날 섞어 풀었을 때의 합산 규칙이 없습니다. 문제별 필요량의 역수를 credit으로 계산해 합이 1 이상이면 완료로 판정합니다. 예: 기본 규칙에서 Silver 1문제(0.5) + Bronze 2문제(0.666...)도 완료입니다.

A형 취득자의 BOJ 최소 난이도 Silver 3 규칙은 멤버별 자격 속성이 필요하므로 `hamster_study_members.boj_minimum_difficulty` 필드를 두었으며 실제 판정/UI 적용은 후속 범위입니다.

## PWA / 반복 사용 UX
- Web App Manifest의 `display: standalone`과 `/dashboard` start URL을 사용합니다.
- Chromium 계열은 install prompt를 이용하고 iOS Safari는 `홈 화면에 추가` 안내를 제공합니다.
- Service Worker는 인증 API와 navigation을 cache하지 않습니다.
- Service Worker가 Web Push 수신과 notification click을 처리합니다.
- 로그인 session은 localStorage에 유지하고 refresh token을 자동 갱신합니다.
- 사용자가 설정에서 직접 로그아웃하면 session을 종료합니다.

## MVP 범위
- GitHub OAuth 로그인 및 session 유지
- Study / Member / Repository 연결 schema
- 첫 사용 onboarding과 초대 코드 참여
- GitHub App 설치와 push webhook 수집
- BaekjoonHub BOJ / Programmers / SWEA 자동 파싱
- 사진 없는 간편 수동 인증
- Study Day(04:00) 판정
- credit 기반 하루 완료 판정
- FIFO backlog 기반 미루기 / 미리 풀기 / 벌금 계산 도메인 함수
- 월간 캘린더 중심 PWA Dashboard
- 모바일 주간/월간 전환
- 멤버별 월간 통계
- Study 멤버별 월별 풀이량 / 난이도 분포 / 주간 추세 / 최근 3개월 도전 수준 통계
- Study 참여원 공용 인증 규칙 설정과 규칙 변경 이력
- 인증 완료 / 미인증 Web Push 알림
- Chrome Extension/SWEA/CodeTree를 위한 authenticated manual ingestion endpoint

## 후속 범위
- SWEA/CodeTree 전용 Chrome Extension
- 기존 Notion history import
- A형 취득자 최소 난이도 판정 UI
- 여러 Study 전환 UI
