# Calendar Dashboard Plan

## 목표
햄쮸터의 메인 화면을 카드형 오늘 현황에서 월간 캘린더 중심 화면으로 전환합니다. 기존 Notion 인증 캘린더처럼 한 달의 흐름과 같은 Study에 속한 멤버별 상태를 한눈에 확인하되, 풀이 상세·미루기·Repository 연결 같은 부가 기능은 맥락에 맞는 패널로 분리합니다.

## 정보 구조

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 🐹 햄쮸터 알고리즘    2026년 9월   <  오늘  >              설정 ⚙ │
│ 멤버 3 · 완료 42 · 미루기 3 · 미제출 2                              │
├──────────────────────────────────────────────────────────────────────┤
│ 일        월        화        수        목        금        토        │
│                                                                      │
│ 6         7         8         9         10        11        12       │
│ 정세진 ✅ 정세진 ✅ 정세진 ✅ 정세진 ✅ 정세진 ✅ 정세진 🟡 ...      │
│ 박현성 ✅ 박현성 ✅ 박현성 ⏭ 박현성 ✅ 박현성 ✅ 박현성 ✅ ...      │
│ 이현수 ❌ 이현수 ✅ 이현수 ✅ 이현수 ✅ 이현수 ✅ 이현수 🟡 ...      │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

- 같은 Study의 멤버만 날짜 셀에 표시합니다.
- 완료 `✅`, 진행 중 `🟡`, 미루기 `⏭`, 미제출 `❌`, 선풀이 `●` 상태를 이름과 함께 표시합니다.
- 날짜 셀 전체가 클릭 타깃이며 오늘은 테두리와 Today badge로 구분합니다.
- 월 이동은 이전/다음 화살표와 `오늘` 버튼으로 제공합니다.

## 날짜 상세 패널
Desktop에서는 오른쪽 Side Sheet, mobile에서는 Bottom Sheet로 표시합니다.

```text
9월 11일 목요일
04:00 ~ 다음 날 03:59 기준

박현성                         ✅ 완료
BOJ 24479 · Silver II           0.5
BOJ 1234 · Silver III           0.5
인정량 1.00 / 1.00

정세진                         ⏭ 미루기
23:41 신청

[오늘 미루기]   ← 오늘이며 본인이 아직 미루지 않은 경우
```

날짜 상세에는 각 멤버의 해당 날짜 직접 풀이, 난이도, 인정 credit, 벌금 정보를 표시합니다. 선풀이로 완료된 미래 날짜는 `선풀이로 확보됨`을 명시합니다.

## 설정 패널
매일 사용하지 않는 기능은 메인 캘린더에서 제거하고 설정 패널로 이동합니다.

- GitHub Repository 연결
- 연결된 Repository 목록 및 과거 기록 가져오기
- Study 초대 링크 복사
- Study ID, installation id 같은 내부 식별자는 노출하지 않음

## 반응형
- Desktop: 7열 월간 캘린더 + 오른쪽 Side Sheet
- Tablet/mobile: 7열 캘린더를 유지하되 이름/상태를 압축하고, 상세는 화면 하단 Bottom Sheet
- 상태는 색상만으로 표현하지 않고 텍스트/아이콘을 함께 사용합니다.

## 데이터 계약
`GET /api/dashboard?month=YYYY-MM`가 요청 월의 날짜별 멤버 상태와 상세를 반환합니다.

- 현재 Study membership을 기준으로 조회해 다른 Study의 멤버는 포함하지 않습니다.
- 멤버 가입일 이전 날짜는 `inactive`로 처리합니다.
- 현재 이후 날짜는 미리 풀기 credit이 확보된 경우 `presolved`, 아니면 `upcoming`으로 처리합니다.
- 기존 04:00 Study Day와 credit/presolve 판정 함수를 그대로 사용합니다.
- DB schema 변경 없이 기존 submissions/postponements/penalties를 projection합니다.

## 접근성 / UX
- 날짜 셀은 button으로 구현하고 선택 상태를 `aria-pressed`로 전달합니다.
- Sheet는 dialog semantics와 닫기 버튼을 제공합니다.
- Escape로 열린 패널을 닫을 수 있습니다.
- Repository 연결이 미설정된 경우 클릭을 조용히 무시하지 않고 사용자에게 원인을 표시합니다.
- 복사, backfill, 미루기 결과는 브라우저 alert 대신 화면 Toast로 피드백합니다.
