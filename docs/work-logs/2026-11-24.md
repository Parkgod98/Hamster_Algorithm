# 2026-11-24 작업 로그

## 월간 달력과 로그인 전 예시

- 모바일 월간 달력은 날짜마다 내 상태와 완료 인원만 표시했고, 큰 화면에서도 네 번째 멤버부터 이름이 생략됐다. 같은 날의 완료·미루기·미제출을 비교할 수 있도록 날짜 칸에 참여 중인 모든 멤버의 닉네임, 아이콘, 상태 이름을 함께 표시한다.
- 보충으로 지난 날짜의 의무를 채우면 해당 날짜에 ‘보충 완료’라고 표시한다. 로그인 전 예시에는 한 주 동안 가상의 세 멤버가 남긴 기록을 실제 달력과 같은 색과 아이콘으로 표현한다.
- 좁은 화면에서 상태 단어가 한 글자씩 끊기지 않도록 두 줄로 배치한다. 긴 닉네임은 날짜 칸의 전체 폭 안에서 줄을 바꾼다. 인증 판정, 저장, 조회 API와 데이터베이스는 그대로 사용한다.
- 로컬 브라우저에서 320px·390px 월간 달력의 2인·4인 기록과 긴 닉네임을 확인했다. ‘미루기’와 ‘미제출’은 한 줄에 들어가며, 1024px에서는 로그인 전 일주일 예시가 한 화면에 보인다. 모바일에서는 예시 안에서 좌우로 넘겨 일요일까지 볼 수 있다.
