# 2026-09-14

## 목표
햄쮸터 PWA에서 인증 완료 즉시 알림과 23:30 미인증 reminder를 제공해 사용자가 직접 앱을 확인하지 않아도 오늘 상태를 알 수 있게 합니다.

## 변경 내용
- 기기별 Web Push subscription을 저장하는 `hamster_push_subscriptions`를 추가했습니다.
- 인증 완료/미인증 reminder on/off를 저장하는 `hamster_notification_preferences`를 추가했습니다.
- `(study,user,Study Day,kind)` 단위로 중복 알림을 막는 `hamster_notification_deliveries`를 추가했습니다.
- Service Worker에 `push` / `notificationclick` 처리를 추가했습니다.
- Dashboard에 🔔 알림 설정 UI를 추가했습니다.
- Android 지원 브라우저/PWA와 iPhone 홈 화면 PWA에서 Push subscription을 만들 수 있게 했습니다.
- GitHub webhook과 수동 인증 API에서 현재 Study Day 상태를 제출 전/후 비교하고 `미완료 → 완료`일 때만 완료 알림을 보냅니다.
- 매일 23:30 KST reminder cron을 추가했습니다. 완료 또는 미루기 상태는 제외합니다.
- reminder 문구는 `🐹 아직 오늘 인증이 안 됐어. 04:00 전까지 풀거나 미루기 신청해줘! 쮸!`로 고정했습니다.
- 만료된 Push endpoint가 404/410을 반환하면 구독 row를 제거합니다.
- VAPID key는 환경변수로만 관리하고 private key는 Repository에 저장하지 않습니다.

- completion 상태 전환 판정 테스트
- 완료/미루기 reminder 제외 테스트
