## 최근 3개월 풀이량 레이아웃 수정

## 목표
성장 통계의 `최근 3개월 풀이량` 카드에서 월별 박스가 카드 하단을 넘어가며 정렬이 틀어지는 문제를 수정합니다.

## 변경 내용
- `growth-recent-card`를 세로 flex container로 변경했습니다.
- 제목 영역은 고정 높이 흐름으로 두고 월별 영역만 남은 높이를 사용하도록 분리했습니다.
- `growth-months`의 `height: 100%`를 제거하고 `flex: 1`, `min-height: 0`을 적용했습니다.
- 월별 3열은 `minmax(0, 1fr)`로 유지해 좁은 폭에서도 카드 내부를 넘지 않게 했습니다.

## 변경 이유
기존 `growth-months`의 `height: 100%`가 제목 영역 높이까지 포함한 카드 전체 높이를 다시 차지해, 제목과 월별 영역의 합이 부모 카드 높이를 초과했습니다.

## 검증
- Repository Harness와 Vercel Preview를 PR CI에서 확인합니다.
