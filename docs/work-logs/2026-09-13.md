# 2026-09-13

## 목표
BaekjoonHub에 올라오지 않는 풀이도 사진 저장 없이 가볍게 수동 인증하고, BaekjoonHub에 올라오는 SWEA 풀이도 자동 인증되게 합니다.

## 변경 내용
- 날짜 상세에서 본인 풀이를 `플랫폼 / 난이도 / 문제 수`만 입력해 수동 등록할 수 있게 했습니다.
- 지원 플랫폼은 기존 Rule Engine과 동일한 BOJ, Programmers, SWEA, CodeTree입니다.
- 문제 번호, 문제명, 사진, 메모는 받지 않습니다.
- 같은 난이도 구간은 내부 synthetic problem id를 재사용하고, 실제 인증 건수만 `hamster_submissions`에 `source=manual`로 저장합니다.
- 자동 풀이와 수동 풀이 credit을 같은 Rule Engine으로 합산합니다.
- 미래 날짜와 스터디 참여 전 날짜에는 수동 등록할 수 없습니다.
- 날짜 상세에서 수동 등록 건은 `수동` 배지로 구분합니다.
- 별도 DB migration이나 Storage bucket 추가 없이 기존 submissions/problems schema를 재사용합니다.
- 실제 BaekjoonHub SWEA 경로 `SWEA/D5/3308...`를 자동 파싱하도록 추가했습니다.
- 같은 SWEA 문제의 README와 소스 파일이 한 commit에 함께 들어와도 문제 1개로만 인증합니다.
- 수동 인증 문제 수 필드는 포커스/클릭 시 기존 값 전체를 선택해 기본값 `1` 뒤에 `2`가 붙어 `12`가 되는 입력 문제를 막았습니다.

## 검증
- 수동 인증 입력 정규화 테스트
- 플랫폼 및 문제 수 유효성 테스트
- synthetic problem id 테스트
- Study Day 내부 solved_at 배치 테스트
- SWEA D5 실제 BaekjoonHub 경로 파싱 및 중복 제거 테스트
- 기존 BOJ 파싱 회귀 테스트
- 기존 Harness의 validate / Git convention / Supabase isolation / PWA / lint / typecheck / build / test를 PR CI에서 확인합니다.
